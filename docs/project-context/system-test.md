## Flows หลัก

- [ ] admin — `/admin/setup` ครั้งแรก → ได้ Admin และ role ระบบ 4 ตัว (admin/engineer/manager/viewer) ถูกสร้าง
- [ ] engineer — บันทึกผลตรวจน้ำมันของเครื่องหนึ่ง → Health/Status ของเครื่องนั้นเปลี่ยนตามผล
- [ ] engineer — บันทึกผลงวดในอนาคต → ถูกปฏิเสธ
- [ ] engineer — นำเข้าไฟล์แล็บซ้ำงวดเดิม → ระบบถาม "ยืนยันทับ" ก่อนเขียน
- [ ] viewer — เปิดหน้าบันทึกผลตรวจด้วย URL → เปิดได้แบบอ่านอย่างเดียว ขึ้น "ไม่มีสิทธิ์บันทึกผล" และไม่มีปุ่มบันทึก (viewer มี `dataentry:read` — ตรงตารางสิทธิ์ของเจ้าของ ยืนยัน 2026-11-18)
- [ ] admin — ลบ role ระบบ → ทำไม่ได้
- [ ] ผู้ใช้ที่จำกัด `SiteAccess` — เห็นเฉพาะโรงงานของตัวเอง
- [ ] ส่งรายงานทางอีเมล → เข้า Mailpit (container) / ผู้ถือ `dev-mode:enable` (live)
